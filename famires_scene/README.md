# Famires Observation Scene（ファミレス・夜のシーン）

アップロードいただいた動画（夜のファミレスで男女が向かい合ってパフェを食べる／話す
シーン）を、**Blender 上でスクリプトから自動生成**するプロジェクトです。

- 男性キャラと女性キャラが**はっきり区別できる**（髪型・体型・服の色）
- 男性が**右手のスプーンを口へ運ぶ「食べる」アニメーション**（ループ）
- 女性は相づちの揺れ
- カメラが**ゆっくり寄っていくドリーイン**（元動画と同じ 15 秒 / 24fps）
- ファミレスの**ボックス席・テーブル・パフェ・夜景の窓・暖色のペンダント照明**

> ⚠️ 重要：これは「スクリプトで作る簡易〜中程度のスタイライズド3Dシーン」です。
> 元動画のような**実写そっくりの人間**は、スクリプトだけでは作れません。
> 実写風にしたい場合は本READMEの「リアル化（実写風）への差し替え」を参照してください。

---

## 1. 必要なもの

- **Blender 4.x または 5.x**（無料）: https://www.blender.org/download/
  - スクリプトは 4.x / 5.x 両対応です（入力名・コンポジタAPIの差を吸収済み）。

## 2. 使い方

### A. Blender の画面で実行（おすすめ）

1. Blender を起動
2. 上部タブの **Scripting** を開く
3. **Open** で `build_scene.py` を読み込む
4. **▶ Run Script**（または `Alt+P`）を押す
5. 数秒でシーンが組み上がります。`0` キーでカメラ視点、スペースで再生

### B. コマンドラインで実行（自動レンダリングまで）

```bash
# シーンを組んでアニメーションを連番PNGで書き出す
blender --background --python build_scene.py --render-anim

# 1枚だけ試し出し（中間フレーム）
blender --background --python build_scene.py --render-frame 180
```

出力先は `.blend`（または作業フォルダ）の `render/famires_####.png` です。
（`build_scene.py` の `OUTPUT_PATH` で変更可能）

### 連番PNGを動画(mp4)にする

Blender の VSE でもできますが、ffmpeg が手軽です:

```bash
ffmpeg -framerate 24 -i render/famires_%04d.png -c:v libx264 -pix_fmt yuv420p famires.mp4
```

## 3. 主な調整ポイント（`build_scene.py` 冒頭の設定）

| 変数 | 意味 |
|------|------|
| `FPS`, `DURATION_SEC` | フレームレート / 尺（既定 24fps・15秒） |
| `RENDER_SAMPLES` | 描画サンプル数。きれいにするなら 128〜256 |
| `RES_X`, `RES_Y` | 解像度（既定 1280×720） |
| `COL_MALE_JACKET` 他 | 服・髪・肌の色 |
| `FORCE_BLOOM` | 5.x でも照明のブルーム（滲み）を使う場合 True |

### レンダーエンジンについて
- 既定は **EEVEE**（速い）。
- **よりリアル**にしたい場合は `setup_render()` 内の
  `# scene.render.engine = "CYCLES"` のコメントを外して Cycles に切り替えてください
  （`RENDER_SAMPLES` を 128 以上推奨。時間はかかります）。

## 4. リアル化（実写風）への差し替え 🔧

スクリプトの人物は「スキンモディファイア＋サブサーフ」で作った滑らかな簡易人体です。
**実写に近づける**には、人物だけを下記の無料アセットに置き換えるのが近道です。

### 手順の概要

1. **体型を作る — MakeHuman（無料）** https://www.makehumancommunity.org/
   - 男性・女性の体型・顔・髪・服をGUIで作成
   - `.mhx2` / `.fbx` でエクスポート
2. **動きを付ける — Mixamo（無料 / Adobe）** https://www.mixamo.com/
   - 体をアップロード → 自動リギング → 「Sitting」「Eating」等のモーションを適用
   - `.fbx`（with skin）でダウンロード
3. **Blender に取り込む**
   - `File > Import > FBX` で男女2体を読み込み
   - 本スクリプトで生成した `Male_*` / `Female_*`（簡易人体）を削除し、
     インポートした人物を椅子の位置（男性 `y=-0.95`、女性 `y=0.95`、`z≈0.62`）に配置
4. **環境はそのまま流用**
   - 席・テーブル・パフェ・夜景・照明・カメラはスクリプト生成物をそのまま使えます
5. **顔・肌の質感**
   - リアル肌は Principled BSDF の `Subsurface Weight` を 0.1〜0.3、
     できればテクスチャ（カラー/法線）を割り当てると一気に実写感が出ます

### さらに上を目指すなら
- **キャラ生成アドオン**: Human Generator / MB-Lab（より実写寄りの人体）
- **髪**: Blender の Hair（カーブ）システムで本物の髪に
- **HDRI 照明**: 夜の室内HDRIをワールドに入れると光が自然になります

## 6. 既知の制約

- スクリプト生成の人物は**スタイライズド**です（実写ではありません）。実写風は §4 を参照。
- ブルーム（照明の滲み）は Blender 4.x で自動有効、5.x は安全のため既定オフ
  （`FORCE_BLOOM=True` で有効化）。
- 髪・服は簡易メッシュです。質感を上げるにはテクスチャ/ヘアシステムを追加してください。
