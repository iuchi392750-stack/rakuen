# FAMICOM GRAND PRIX — Unity プロジェクト

ポールポジション風の疑似3Dレースゲーム。**シーンの組み立てまでコードが自動で行う**ので、
スクリプトを入れて再生ボタンを押すだけで動きます。手作業での配置・接続は一切ありません。

---

## 使い方(このフォルダをそのまま開くだけ)

1. **ZIPを展開**して、好きな場所に置く(例:`C:\新Suno\FamicomGP`)
2. **Unity Hub → Add → 展開したフォルダを選択**
3. **開いて、再生ボタンを押す**

これだけです。プロジェクトを開いた瞬間に `Assets/Scenes/Race.unity` が自動生成されて開き、
再生するとコース、背景、マシン4台、カメラ、HUD、効果音がすべて自動で組み上がります。
**シーンに何かを配置したり、コンポーネントを接続したりする作業は一切ありません。**

Unity のバージョンは 2022.3 系で作ってありますが、それより新しい Unity(Unity 6 など)で
開いた場合は、Hub がアップグレードを提案してくるので、そのまま進めれば動きます。

> シーンが開いていない状態で再生しても動きます(空のシーンでも自動的に起動します)。
> メニューバーの **Famicom GP → Play Now** からでも起動できます。

### すでにあるプロジェクトに組み込む場合

`Assets/FamicomGP/` フォルダだけをコピーしてください。あとは同じで、再生すれば動きます。

## 操作

| キー | 動作 |
|---|---|
| ← → / A D | ステアリング |
| ↑ / W / Z | アクセル |
| ↓ / S / X | ブレーキ |
| **SPACE** | レース開始 / リトライ |
| **TAB** | デモ走行モードに戻る |
| **M** | 消音 |

---

## デモ走行モード(録画用)

起動直後は **アトラクトモード**で、AIが自動でコースを1周します。放置しておけば延々と
走り続けるので、**画面録画すればそのまま動画素材になります**。

デモドライバーは先のカーブを読んで減速し、前のマシンを避けて抜いていくので、
人が走らせているように見えます。SPACEでプレイヤー操作に切り替わり、TABでデモに戻ります。

自動でデモを始めたくない場合は、Inspector の `Start In Demo Mode` をオフにしてください。

---

## ゲーム内容

4番手グリッドからスタートし、1周でオレンジ・緑・黄の3台を抜いて **1位でゴール**すれば勝ち。
コースアウトすると減速します。1位でゴールするとベストタイムが記録されます。

---

## レトロな見た目のしくみ

- **320×180 の RenderTexture に描画し、Point フィルタで画面いっぱいに拡大**しています。
  これがドットの粗さの正体で、後処理のフィルタではありません
- マテリアルはすべて **Unlit(ライティングなし)**。フラットな塗りがファミコン的な平面感を作ります
- マシンのスプライトは **実行時に24×16ピクセルで描き起こしています**。画像ファイルの
  インポートは不要で、カラーリングは `CarArt.cs` の `Livery` を書き換えるだけで変更できます
- 効果音は **矩形波を実行時に合成**しています(エンジン音は速度でピッチが変わります)

解像度を変えたい場合は `RetroDisplay.cs` の `Width` / `Height` を書き換えてください
(例:256×224 にすると、より本物のファミコンに近い比率になります)。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `GameBootstrap.cs` | シーン全体を自動生成。**これだけをアタッチすればよい** |
| `AutoLaunch.cs` | 空のシーンでも再生時に自動起動させる |
| `Editor/SceneInstaller.cs` | 初回起動時にレースシーンを自動作成(エディタ専用) |
| `TrackBuilder.cs` | コースの生成(センターライン+路面・縁石・白線・チェッカーのメッシュ) |
| `Racer.cs` | マシンの挙動。プレイヤー操作・デモ走行AI・ライバルAIを兼ねる |
| `RaceManager.cs` | レース進行、順位、タイム、HUD、効果音 |
| `RetroDisplay.cs` | 低解像度レンダリングとチェイスカメラ |
| `Backdrop.cs` | 空・雪山・観客席の背景(カメラを囲む円筒) |
| `CarArt.cs` | マシンのドット絵スプライト生成 |
| `Palette.cs` | 配色とマテリアル |
| `Keys.cs` | 入力(新Input System環境でも落ちないようガード) |

## うまく動かないとき

**車が操作できない / キー入力が効かない**
プロジェクトが新しい Input System 専用になっています。
`Project Settings > Player > Active Input Handling` を **Both** に変更してください。
(この状態でもデモ走行は動き続けるので、画面は止まりません)

**画面が真っ青で何も出ない**
Console にエラーが出ていないか確認してください。スクリプトのコンパイルが通っていれば、
再生時に自動でシーンが組み上がります(既存の Main Camera があっても自動で無効化するので、
削除する必要はありません)。

**背景が黒い / テクスチャが出ない**
URP環境で `Unlit/Texture` シェーダーが見つからない場合に起こります。
`Project Settings > Graphics` でシェーダーが除外されていないか確認してください。

## コースを変更したい

`TrackBuilder.cs` の `Build()` にある `Section(セグメント数, カーブ角/セグメント, 高低差/セグメント)`
の並びがコースレイアウトです。数字を書き換えるだけでコースが変わります。

```csharp
Section(70,  0f,    0f);     // ストレート
Section(60,  0.9f,  0.06f);  // ゆるい右カーブ+登り
Section(80, -1.5f,  0f);     // 左カーブ
```

カーブ角がプラスで右、マイナスで左。高低差がプラスで登り、マイナスで下りです。
