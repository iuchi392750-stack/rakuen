# 夕凪の鯨 — 沖縄の海で出会う奇跡
*The Whale of the Evening Calm*

Seedance 2.0 用ショートフィルム企画・改訂版(15秒 / X公開向け)
※旧版「ガラスの鯨と夏の屋上」(屋上編)からの舞台変更版

## ログライン

夏の終わり、沖縄。海水浴客もまばらな夕暮れのビーチをひとり歩く少女の前で、海から飛び上がった鯨が潮を吹きながら、そのまま空へと昇っていく。夕焼けが闇に呑まれるまでの、常闇(とこやみ)の一瞬にだけ起こる奇跡。

## 物語(プロット)

**場所:** 沖縄の遠浅のビーチ。エメラルドの海、白い砂浜、遠くにアダンと椰子のシルエット。人影はほとんどない。
**時間:** 8月末、日没直後のマジックアワー。空の低いところはまだ燃えるようなオレンジ、高いところはすでに藍色の夜が始まっている。

**起:** 家族旅行の最終日。少女・**ナギ**(16歳、白いワンピースに麦わら帽子、サンダルを手に持ち裸足)は、夕食前のひととき、ひとり波打ち際を歩いている。濡れた砂に足跡が続き、引いていく波が夕焼けを鏡のように映す。昼間の賑わいが嘘のように、ビーチには波の音だけが残っている。

**承:** ふいに、沖の海面が大きく盛り上がる。次の瞬間、**巨大なザトウクジラ**が水面を割って躍り出る。全身から滝のように海水が流れ落ち、噴き上げた潮が夕日を受けて**金色の飛沫の柱**になる。ナギは息を呑んで立ち止まる。麦わら帽子が風にさらわれそうになり、手で押さえる。

**転①:** 我に返ったナギは、**慌ててショルダーポーチからカメラを引っ張り出す**。焦る指がストラップに絡まり、麦わら帽子が砂浜に落ちるのにも構わず、震える手でレンズを沖へ向ける。ファインダーの中——鯨は海へ落ちない。重力を忘れたように、ゆっくりと**空へ昇りはじめている**。夢中でシャッターを一度切る。

**転②:** だが、体から零れる海水が光の尾を引いて昇っていくその姿は、小さなファインダーには収まりきらない。ナギはゆっくりとカメラを下ろし、**自分の目で見ることを選ぶ**。波打ち際まで駆け出し、膝まで海に浸かって見上げる。スカートの裾が波に濡れるのも構わずに。

**結:** 鯨は、オレンジの夕焼けと藍色の夜が溶け合う**常闇の境界**へと昇っていく。空の高みで潮をもうひと吹き——その飛沫が散って、**夜の最初の星々**になる。鯨のシルエットは藍色に溶けて見えなくなり、あとには星の生まれた空と、暗くなった浜でカメラを胸に抱きしめて佇むナギだけが残る。波が静かに彼女の足跡を消していく。写真に残ったのはたった一枚。それでも本当の奇跡は、彼女の目の中にだけ焼き付いている。

**テーマ:** 「昼と夜のあわい(常闇の一瞬)にだけ開く扉」。夕焼けから夜への色彩のグラデーション自体を物語の主役として描く。

## キャラクターデザイン — ナギ(凪)

- 16歳。肩下の黒髪(潮風で揺れるおくれ毛)、日に焼けた素肌
- 白いノースリーブのワンピース、麦わら帽子(あご紐なし・手で押さえる仕草)、サンダルは手に持ち裸足
- **小さなショルダーポーチにコンパクトカメラ**(旅の思い出用。ストラップ付きの銀色のデジカメ)
- 感情:物憂げな散歩 → 息を呑む驚き → 慌ててカメラを構える焦り → カメラを下ろす決断 → 衝動的に海へ駆け込む → 星空を見上げる静かな余韻
- カット4の「膝まで海に入って見上げる逆光シルエット」が本編のキービジュアル。カット3の「震える手でカメラを構える横顔」が感情のクローズアップ

## 美術・光・色設計

- スタイル:劇場アニメクオリティ(新海誠的な光と雲の密度)。リアル調に振る場合は下記プロンプトの差し替えで対応
- **色のドラマツルギー:** 画面の色温度を15秒かけて約2000K分下げる。カット1=金色(3000K相当の暖色)→ カット4=群青と星明かり。この移ろいが「常闇の一瞬」の表現そのもの
- 海:沖縄特有のエメラルド→夕色を映す鏡面→夜の黒い海、と3段変化
- 鯨:実在のザトウクジラの質感。体表を流れ落ちる海水と潮吹きの飛沫が最重要ディテール。昇天時は腹側に夕焼けの照り返し
- 星:潮の飛沫が星に変わる瞬間は「飛沫の白 → 光の粒 → 瞬く星」の3段階でモーフさせる

## 音響設計(Seedance ネイティブ音声)

1. 寄せては返す波、遠くでひぐらし(0–2.5s)
2. 海面が割れる轟音と水の壁が崩れる音、続いて鯨の歌(2.5–5.5s)
3. ポーチのジッパー音、焦る衣擦れ、**カシャッというシャッター音一回**。鯨の歌が遠くで続く(5.5–8.5s)
4. 音がすっと引き、静謐なストリングス+ピアノが立ち上がる。波を蹴る足音と水滴の音だけが近くに(8.5–12s)
5. 高空の潮吹きの残響 → 夜の虫の声と波音だけが残る(12–15s)
