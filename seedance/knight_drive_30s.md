## プロンプト本文(そのまま貼り付け)

```
【素材の定義】
@Image 1 ＝ <ドライバー>。使うのは顔立ち・髪型・肌の質感・黒いレザージャケット・
チャコールグレーのTシャツ・インディゴのジーンズ・黒いブーツのみ。
白いスタジオ背景と左右2分割のレイアウトは使わない。

@Image 2 ＝ <ブラッククーペ>。使うのは車体のウェッジ形状・光沢のある黒い塗装・
ベルトラインの細い赤いピンストライプ・黒い5本スポークホイール・濃いスモークガラス・
フロントノーズを横切る赤いスキャナーライトのみ。
白いスタジオ背景と三面図のレイアウトは使わない。出力には常に1台だけ映す。

@Image 3 ＝ <ハイウェイ>。使うのは空間・濡れた路面の質感・オレンジの街灯の配置・
地平線の街明かり・低く漂う霧・照明のみ。

@Image 4 ＝ <ネオン街>。使うのは空間・両側の高層ビル・マゼンタとシアンのネオン・
濡れたアスファルトの反射・照明のみ。

【一貫性の維持】
<ドライバー>は全編で1人だけ。顔・髪型・服装は最後まで変えない。
<ブラッククーペ>は全編で1台だけ。車体色・赤いピンストライプの位置・
スキャナーライトの位置は変えない。
スキャナーライトは常にフロントノーズを左右に往復する赤い光の帯として描く。
他の人物・他の車は登場させない。

【ステージ1】
初期状態:雨上がりの<ネオン街>。<ブラッククーペ>が歩道脇に停車し、車体は画面右を向く。
運転席は無人。スキャナーライトは消灯。<ドライバー>が画面奥から歩いてくる。
主要イベント:<ドライバー>が運転席のドアを開けて乗り込み、ドアを閉める。
決意の手がかり:視線がまっすぐ前方の道路へ向く。顎がわずかに引かれる。
ドアを閉める直前に一度だけ深く息を吐く。
カメラ:濡れた路面を映すローアングルのワイドから、乗り込む<ドライバー>のミディアムへ寄る。
終了状態:<ドライバー>は運転席に座り、両手はステアリングの上。ドアは閉じている。
スキャナーライトが点灯し、赤い光が左右に往復しはじめている。車体は画面右を向いたまま。

【ステージ2】
前段から継続:<ドライバー>の同一性と服装は不変。<ブラッククーペ>は同一の1台。
スキャナーライトは点灯したまま左右に往復を続ける。
主要イベント:<ブラッククーペ>が発進し、<ハイウェイ>へ出て加速する。
カメラ:リアタイヤのエクストリームクローズアップから、車体と並走するトラッキングショットへ。
背景の街灯が規則的に後方へ流れる。
終了状態:<ブラッククーペ>は<ハイウェイ>の中央車線を高速走行している。
濡れた路面に赤いスキャナーの光と街灯のオレンジが尾を引いて映り込む。車体は画面奥へ向かう。

【ステージ3】
前段から継続:走行速度と進行方向は不変。<ドライバー>は運転席のまま。
主要イベント:カメラが車体を追い越して正面に回り込み、そのまま後方へ引いていく。
カメラ:並走のトラッキングから、フロントノーズ正面のミディアムを経て、
路面すれすれの高さで大きく引くワイドへ。
終了状態:<ブラッククーペ>は画面中央の遠方にあり、赤いテールランプの2点と
フロントの赤いスキャナーの光だけが霧の中に残る。両側の街灯が地平線へ収束している。

【ビジュアル】
1980年代ネオノワールの空気。深い黒とオレンジの街灯、マゼンタとシアンのネオン。
濡れた路面の強い反射。アナモルフィックレンズのフレア。自然なフィルムグレイン。
コントラストは高く、暗部を沈ませる。

【音声】
(低く脈打つシンセベースのアナログシンセ音楽。ステージ2の発進と同時に立ち上がる)
<雨上がりの水たまりを踏む足音><車のドアが閉まる重い音><スキャナーライトの電子的な明滅音>
<V8エンジンの始動音とアイドリング><タイヤが濡れた路面を切る音><風切り音>
台詞の言語:日本語。落ち着いた合成音声の男性的な声で、車載AIが感情を抑えて淡々と言う:
{準備はいいか。}
```

## PixVerse で回す場合

PixVerse 側で Seedance 2.5 を選び、上記4枚をアップロードしてから本文を貼り付けます。
`@Image 1`〜`@Image 4` の番号が**アップロード順と一致しているか**を必ず確認してください。
順番が入れ替わると人物と車の定義が入れ替わります。

## この30秒で守った作法(ガイド対応)

| ガイド | この企画での適用 |
|---|---|
| FIG 01 5ブロック | 主体+動作を各ステージ冒頭に置き、場所・ビジュアル・カメラ・音声を後続で足した |
| FIG 02 使う/使わない | 4枚すべてに「使うのは〜のみ」「〜は使わない」を明記。車は「常に1台だけ」と個数を固定 |
| FIG 03 音の括弧 | 音楽 `( )`、効果音 `< >`、台詞 `{ }` を使い分け。台詞は言語を宣言 |
| FIG 05 1ステージ1変化 | 乗り込む / 発進して加速する / カメラが回り込んで引く、の3つに限定 |
| FIG 05 終了状態 | 各ステージの終わりを「フレームを止めて確認できる事実」で記述 |
| FIG 07 自動ロック | 比率・尺・解像度をプロンプト本文から排除し、UI設定として分離 |
| FIG 13 感情の翻訳 | 「決意」を視線・顎・呼吸の3つの手がかりに置き換えた |
| FIG 14 カメラ用語 | 標準用語はそのまま使用。回り込みだけ動きの方向と高さを補足 |

## 調整するときの勘所

- **秒配分を効かせたい場合**:各ステージの冒頭に `0〜10秒` `10〜20秒` `20〜30秒` を足す。
  ガイドの通り連続・非重複のレンジにすること
- **台詞を英語にする場合**:`台詞の言語:アメリカ英語。落ち着いた合成音声の男性的な声で
  車載AIが淡々と言う:{Ready when you are.}` に差し替える
- **主人公の乗車シーンをもっと見せたい場合**:ステージ1を2つに割り、
  「車へ歩み寄る」と「乗り込む」に分ける(1ステージ1変化を守る)
