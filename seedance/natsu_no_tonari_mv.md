# 夏のとなり — 青春MV企画

90秒(15秒 × 6カット)/ 16:9 / アニメ調
歌:Suno / 映像:Hailuo MiniMax H3

---

## ログライン

高校最後の夏。幼なじみの彼のとなりは、世界でいちばん近くて、いちばん遠い。
言えないまま終わっていく夏を、six の情景で綴るモンタージュMV。

## 感情の設計

MVの軸は「**距離**」。物理的にはずっと隣にいるのに、心の距離だけが縮まらない。
6カットで **近づく → はぐれる → 言えない → 見送る** の弧を描きます。

最後に彼女が手を振るのは、告白の代わりです。言わなかったことが伝わる終わり方にします。

---

## 登場人物

**ナツ(17)** — 主人公。肩上のボブ、日に焼けた肌、白い半袖セーラー服(紺襟・赤スカーフ)。
夏祭りでは白地に金魚柄の浴衣。表情は快活だが、ふとした瞬間に翳りが出る。

**ソウ(17)** — 幼なじみ。少し背が高く、癖のある黒髪、白いシャツ。
基本は後ろ姿・横顔・シルエットで処理し、顔をはっきり見せない。
**視聴者がナツの視点に同化できるようにするための演出**です。

## 制作手順

1. **キャラクター三面図を作る**(下記プロンプト)→ `natsu_sheet.png` として保存
2. Suno で楽曲を生成 → 90秒に合うセクションを決める
3. Hailuo H3(Omni Reference ON)で `@natsu_sheet` を参照しながら Clip 1 を生成
4. Clip 2以降は**前クリップの最終フレーム**を `last_frame_0X.png` として書き出し、`@last_frame_0X` で参照
5. 6本を連結 → 楽曲を乗せて完成

**キャラクターの一貫性が最重要です。** 三面図を全カットで参照し続けることで、
6カットを通して同じ人物に見えるようにします。

## 連結と音付け(ffmpeg)

```bat
ffmpeg -f concat -safe 0 -i concat.txt -c copy mv_90s.mp4
ffmpeg -i mv_90s.mp4 -i song.mp3 -c:v copy -c:a aac -shortest mv_final.mp4
```

`concat.txt`:
```
file 'clip_01.mp4'
file 'clip_02.mp4'
file 'clip_03.mp4'
file 'clip_04.mp4'
file 'clip_05.mp4'
file 'clip_06.mp4'
```

**音の設計:** 各クリップは環境音のみで生成し、楽曲は後から全体に乗せます。
ただし**カット1の冒頭とカット6の最後だけ環境音を残す**と、
曲の前後に余韻が生まれて作品として締まります。
